# GVM Smart Campus — Project SAKHI

Responsive single-page HTML/CSS/JavaScript prototype.

## Run locally
1. Open this folder in VS Code.
2. Open `index.html` in a browser, or use the Live Server extension.
3. Test navigation, forms, and the SAKHI demo button.

## Publish free with GitHub Pages
1. Sign in to GitHub and create a new **public** repository, e.g. `gvm-smart-campus`.
2. Upload `index.html` to the repository root.
3. Open repository **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select branch `main`, folder `/ (root)`, then Save.
6. Wait for the published URL shown in Pages settings.
7. Open the URL in a private/incognito window and test it on a phone.

## QR code
After the public URL works, use a QR generator such as Canva's QR code generator and paste the exact published URL. Scan the generated QR using another phone to verify it.

## Prototype limits
- Forms store demo submissions in local browser storage only; they do not send data to the college.
- SOS is a demo only; it does not call emergency services, alert anyone, or share location.
- Sample notices/events/opportunities are not official college announcements.
- Obtain college permission and verify contacts before any real pilot.
